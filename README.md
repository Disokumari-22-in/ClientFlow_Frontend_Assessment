# ClientFlow – Business Enquiry Management System

## Candidate
Disokumari

## Selected Track
Track B — Frontend

## Project Overview
ClientFlow is a responsive frontend prototype for capturing, organizing, searching and following up on business enquiries.

## Features Implemented
- Dashboard with pipeline metrics
- Enquiry creation and editing
- Client/company, contact, source, service, budget, status and follow-up fields
- Search and filters for status, source and assigned person
- Enquiry details view
- Follow-up view
- Form validation
- Success, empty and error states
- Responsive desktop/tablet/mobile UI
- Mock data persisted with browser localStorage

## Technology Stack
HTML5, CSS3, JavaScript, Bootstrap 5

## Setup
Open `index.html` in a browser. No backend or build step is required.

## Data
The prototype starts with realistic mock enquiries and stores changes in localStorage.

## AI Usage Declaration
AI was used during development for assistance with project structure, UI implementation, JavaScript logic and documentation. The generated work was reviewed and adapted for this assessment. The candidate remains responsible for understanding and explaining the submitted code.

## Known Limitations
- No backend API
- No authentication
- No shared database
- Local browser storage is used instead of a production data layer
